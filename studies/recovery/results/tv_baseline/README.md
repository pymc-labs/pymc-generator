# Historical recovery studies — compact, static results

This directory republishes the **existing, approved** 50-world TV-NUTS and 50-world constant-baseline bounded least-squares scientific results as a 97-week (7–103) compact numerical snapshot, independent analysis and **executed, ordinary-output Jupyter report**. It is not a new generated/fitted run, and does not approve a new report. The two baseline/outcome regimes and objectives differ: **never compare their percentages as a method ranking.** No ADVI50 results are claimed; the PR1 tiny smoke fits are engineering evidence only.

The three PR previews in `screenshots/` are exact decoded PNG outputs from `report.ipynb`: recovery gates (cell index 5, output 2), pattern failures (cell 10, output 0), and the explicitly selected TV world 0 / C2 contribution example (cell 12, output 0). They are saved figure outputs, not live Jupyter screenshots or recomputed results. Source notebook SHA256: `85a080fdd58ab5b9e29c38b03586b9d41da74b804c0057d95112725b98ea9da7`.

## Design, denominators and provenance

The base original prior is the complete historical `notebooks/ols_study_50_seed10029/manifest.json:config` (104 reported weeks, 8 burn-in, 15 media/10 control slots, 1 latent slot; direct cy/zy, geometric adstock, Michaelis–Menten response). Constant corpus generation used two cells per batch, batch seeds **10029–10053**, producing 50 worlds. The **matched** historical TV intervention used the *same inputs, graph, contributions except intrinsic baseline, parameters and noise realization* as that constant corpus, changed only the baseline with seeds **91001+w**, relative amplitude `[0,.093]` and Beta(2,2) smoothness width up to 26 over 112 full weeks. Scored original weeks 7–103 correspond to full trajectory rows 15–111. The original bounded estimated-transform nonlinear least-squares optimizer used **seed 2026 for every world**, two starts and 120 evaluations per start; this is not unconstrained linear regression. Historical TV four-chain Nutpie `draw_diag` used **92001+w**, 1000 warmup and 1000 draws, target acceptance .95 and max depth 10; conditional baseline reconstruction used **93001+w**; predictive noise used **94001+w**. *Do not replace this paired population with the current PR1 independently generated varying-baseline example.* PR1 is a reusable fresh supported-configuration pipeline, not an exact historical paired experiment replay: its varying data generation is independent instead of this baseline-only intervention, its bounded solver uses a world-offset seed, and its TV conditional baseline reconstruction seed differs. Even common model/seed settings cannot promise identical posterior draws or retrospective source/output certification.

Both historical score gates use `max(0.1 * ||true contribution||₂, 0.01 * ||true noiseless outcome||₂)` on 97 weeks. A world must pass diagnostics/optimizer qualification before any nonzero effect's point recovery is evaluable. World/media/control/total/baseline gates, pattern numerators and denominators (known-zero vs eligible/evaluable/unresolved, overlapping assignments) and TV true-world pass/fail descriptors are **calculated afresh** from the compact arrays/recorded qualification and metadata, not read from old report headline tables. Figures select **TV world 0 C2 (fail), world 12 C6 (pass); bounded world 0 C3 (fail), world 12 C6 (pass)** to illustrate each regime, not represent every world, and show raw spend/true/fitted baseline. TV posterior bands are only pointwise intervals; bounded point optimization has none.

Approved scientific texts are those previously reviewed by **Teemu Säilynoja**, Plannotator `pn-2a768e`, against the **original** report IDs `f2dccfb682b95c9e8da4ffdc0d3f8c5f4134098468d54ef4f8c8e974cfbbffb3` (TV) and `041a2b4bfc17d53631ad524508fe0a6243c8bdf50df47ec3ee567a7c202562de` (bounded). `provenance.json` records their original `review.json`, `review-receipt.json`, `evidence.json`, report manifest/receipt and interpretation digests. Old paths are identifiers at [commit `4dc69ce`](https://github.com/pymc-labs/pymc-generator/tree/4dc69ce/studies/recovery/report-artifacts), *not* dependencies of the compact notebook. Historical manifests prove **legacy input-hash compatibility only**; original per-fit output hashes and a complete original source-file hash inventory were unavailable (some bounded-function/model-text hashes *were* recorded), and later evidence sealing cannot retroactively certify the fitting process. Compact byte hashes certify this supplied snapshot, not fresh science or original chain reproducibility. No independent dataset/source, interventions, predictive calibration, realism or structural identifiability conclusions are established by the static report.

## Run All from a clean PR2 source export (no archived fit/data directories)

Use Python 3.13.12 with the repository's pinned `studies/recovery/requirements-report.txt` (NumPy, pandas, matplotlib, nbformat, nbclient, ipykernel; no widget/Plotly dependency). The committed `report.ipynb` displays without a kernel; to rebuild it from only `snapshot.json`, `snapshot.npz`, `historical-config.json`, two interpretations, `provenance.json`, `analysis.py` and `build_notebook.py`:

```sh
# cd /path/to/CLEAN-PR2-source-export  # no old studies/recovery/report-artifacts, no old notebooks/* fit/data
P=/tmp/recovery-pipeline-export.JV7T5W/studies/recovery/.venv/bin  # example existing isolated env; replace with your installed env/bin
export JUPYTER_PATH=/tmp/recovery-pipeline-export.JV7T5W/studies/recovery/.venv/share/jupyter
export OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 NUMBA_NUM_THREADS=1 PYTHONDONTWRITEBYTECODE=1
$P/python -m pytest -p no:cacheprovider studies/recovery/results/tv_baseline/test_results.py -q
$P/python studies/recovery/results/tv_baseline/build_notebook.py
```

The command writes an executed `report.ipynb` **from compact data only** (or use `--out /path/to/report.ipynb`); the renderer works in its own directory and checks all payload/approved-text hashes before computing. It refuses unknown/nonfinite arrays and status/term mismatches. `export_snapshot.py` needs old evidence *only if you intentionally re-export*, with explicit `--historical-root OLD_COMMIT_TREE --out EMPTY_DIRECTORY`; it is not run by the report. No generation, fitting, sampling, new scientific approval or optional smoothing is part of these commands.
