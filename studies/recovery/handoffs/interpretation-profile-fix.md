## Reproduction and cause

Deterministic initial read-only probe of `tv50-corrected/evidence.json` compared every `worlds[i].profile` to the corresponding `trajectories[str(i)].truth`: **all 50 TV baseline means and all 50 baseline SDs mismatched**. For world 0: old mean 3.5764687061309814 vs scored truth 3.5845318436461295; old SD 0 vs scored truth 0.4554043845587071. For world 1: old mean 6.949382781982422 vs scored truth 6.69939339005436; old SD 0 vs 0.7408779658753725. Media and control temporal SDs already matched scored truth in all 50 TV worlds. The original TV observation residual (`observed - truth.sum(axis=1)`) agrees with source-corpus outcome noise to saved float precision across all 50 (max point difference 1.26e-6, max SD difference 8.0e-8). The problem was **not** wrong score bounds, noise contamination, or changed media/control effects: `_legacy` selected the saved TV truth, but `_profiles` unconditionally calculated baseline mean/SD from the separate **constant-baseline original source corpus**. Bounded constant and historical/current native use the same source baseline as their scored truth, hiding this bug.

Before the fix, added `_assert_profiles_match_scored_truth` at the reader/report seam, called in existing real-50-TV/constant, recorded historical smoke and synthetic current native tests. `OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 PYTHONDONTWRITEBYTECODE=1 studies/recovery/.venv/bin/python -m pytest -p no:cacheprovider tests/test_recovery_task3.py -k legacy_science_reports -q` **failed on the exact reported world 0 mean** (3.5764687061309814 vs 3.5845318436461295). This was a real saved-world regression, not a mocked changed input. The fix passes the exact scored `truth` components into `_profiles`; baseline mean/SD and media/control temporal SD now all derive from the **same saved scored-window truth arrays** used for scoring, plots and known-zero accounting. Noise SD still derives from the source-corpus outcome-noise input over that scored window; media/control mechanism/effect values (carryover, MM multiplier, beta, control coefficient) still derive from the original source corpus. No scoring, trajectory, fitting, generator, provenance-limitation or diagnostic path changed. Regression tests independently compare **all 50** TV and constant-world profile elements with original mechanism/noise corpus and TV saved observation residual, plus both historical constant/varying (all rows) and synthetic native 2/4-world (all rows) truth-profile consistency.
