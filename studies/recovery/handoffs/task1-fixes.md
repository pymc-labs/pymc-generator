Identity may declare the exact expected output filenames; `complete_checkpoint` requires the same inventory, all regular files, records their SHA256 digests in an atomically published receipt; inspection checks inventory and bytes each time, rejects missing/extra/tampered output. No implicit resumption/repair, no complete state without receipt; per-world production inventory definition remains Task 2's responsibility. Negative tests reproduce manifest-only false completion, partial output, premature completion, subset-only inventory claim and tampering.
4. **Malformed nested arrays:** method names and ADVI seeds are checked for scalar string/int types *before* `set()`. Nested arrays raise actionable `ContractError` rather than `TypeError`, locked by tests.
