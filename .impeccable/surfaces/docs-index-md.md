# Documentation site (home + reading pages)

Scope: the whole MkDocs Material site. Visitor mode: Read (the home page opens
with a demonstrative hero, then reads as documentation).
Audience/job: causal-ML researchers and PyMC users learning to generate and
audit worlds. Proof: build-time executed worlds, figures, notebooks; no
invented claims. Constraints: PyMC Labs palette only; minimal copy; figures,
notebooks, and package plots share one style; no LLM-targeted sections.
User steer on the chosen card: more minimal, less text, Atlas-style navbar, a
full-bleed cinematic hero background that reacts to the mouse, cleaner and
whiter with more colour detail.

## Direction contract

THESIS: The docs read as a research publication whose evidence is executed
live: one real seed-0 world fills the opening as a cinematic field you focus
with your cursor. Refuses the centred hero plus feature-card grid.

OWN-WORLD: White ground with soft aqua/periwinkle blooms and peach only on
the focused element; navy ink; Host Grotesk display, Source Serif 4 reading,
Fragment Mono for data labels; white plates with hairlines, a circular loupe,
nodes on hairline chains.

STORY: The visitor sees an actual world, focuses on it, watches code become
its series and exact decomposition, then reads the guides with plates,
rails, and a resume mark.

drifting ghost worlds; loupe follows the mouse and names nodes and
